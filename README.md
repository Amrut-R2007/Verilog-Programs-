#** Digital Logic Vault ⚡**

This is my collection of Verilog HDL files. It’s a mix of basic gate logic, combinational circuits, and sequential blocks I’ve built while exploring digital design and FPGA workflows.

## 📂 What's Inside?
*   **Combinational Logic:** Adders, Muxes, and Encoders.
*   **Sequential Circuits:** Flip-flops, Counters, and State Machines (FSMs).
*   **Hardware Labs:** Implementations based on my curriculum and personal experiments.

## 🛠 Tools I Use
*   **Simulation:** Icarus Verilog  / Vivado.
*   **Hardware:**  Pynq-Z2
